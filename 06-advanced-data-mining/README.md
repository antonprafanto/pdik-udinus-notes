# 📚 Advanced Data Mining (Penambangan Data Lanjut)

Mata kuliah ini diampu oleh **Prof. Ir. Heru Agus Santoso, Ph.D., IPM., ASEAN Eng.** pada Program Doktor Ilmu Komputer (PDIK) Universitas Dian Nuswantoro (UDINUS).

Fokus mata kuliah ini mengeksplorasi paradigma penambangan data tingkat lanjut (*Advanced Data Mining*) di era kecerdasan buatan modern: Multimodal Data Mining, Cross-Modal Pattern Mining, Text-Guided Mining & Retrieval-Augmented Generation (RAG), Explainable AI (XAI) berstandar internasional, Causal Discovery, Fairness-Aware Mining, Graph Neural Networks (GNN), Privacy-Preserving Mining (PPDM) & Federated Learning, serta Spatio-Temporal Streaming Data Mining dan mitigasi Concept Drift.

---

## 📑 Daftar Catatan Pertemuan

* 📄 **[Pertemuan 1: Paradigma Baru Penambangan Data Lanjut, Fusi Multimodal, & Explainable AI](./pertemuan-01-penambangan-data-lanjut-dan-multimodal-mining.md)**
  * *Topik Pembahasan:*
    * Dekonstruksi RPS: Beranjak dari CRISP-DM standar menuju tren riset konferensi & jurnal internasional (*happening topics*).
    * Delapan (8) pilar utama advance data mining kontemporer:
      * **Multimodal Mining & Feature Fusion:** Penyatuan data tabular, teks klinis, dan citra medis menjadi matriks terpadu ($100 \times 2435$), klasterisasi K-Means, dan penambangan aturan FP-Growth (*Disease Phenotype*).
      * **Text-Guided Data Mining & RAG:** Augmentasi kode medis ICD berbasis LLM untuk mendongkrak performa model klasifikasi konvensional.
      * **Explainable AI (XAI):** Membuka kotak hitam (*Black Box*) via SHAP/LIME dan penyelarasan matematis dengan standar internasional WHO pada kasus stunting balita.
      * **Causal Data Mining:** Memisahkan korelasi murni (*spurious correlation*) dengan relasi kausalitas sebab-akibat.
      * **Fairness-Aware Data Mining:** Eliminasi bias gender, ras, dan sosio-ekonomi demi kemampuan generalisasi model lintas demografi.
      * **Graph Mining & GNN:** Transisi dari ontologi semantik menuju Graph Neural Networks (GNN) dan graf dinamis temporal.
      * **Privacy-Preserving Mining (PPDM) & Federated Learning:** Penambangan terdistribusi tanpa pemindahan data mentah (*zero raw data sharing*).
      * **Spatio-Temporal & Concept Drift:** Integrasi data sekuensial waktu (LSTM) dan spasial (CNN) pada sensor IoT *screening* kesehatan masyarakat, serta analogi OOP pada pergeseran konsep (*Class Concept vs Instance*).
    * Telaah metodologis disinformasi/hoaks multimodal (masalah terstruktur vs tidak terstruktur, NER, dan reduksi dimensi teks XAI).
