# 🎓 Catatan Kuliah & Diskusi PDIK UDINUS (Angkatan 2026/2027)

Repositori terbuka ini memuat catatan perkuliahan, resume diskusi kelas, dan ringkasan materi akademik pada **Program Doktor Ilmu Komputer (PDIK)** di **Universitas Dian Nuswantoro (UDINUS)**, Semarang.

Tujuan utama repositori ini adalah sebagai sarana dokumentasi belajar mandiri, refleksi pemikiran riset, dan media berbagi (*sharing knowledge*) antar rekan-rekan mahasiswa doktoral.
