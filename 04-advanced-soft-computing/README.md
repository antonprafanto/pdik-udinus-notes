# 📚 Advanced Soft Computing (Komputasi Lunak Lanjut)

Mata kuliah ini diampu oleh **Prof. Dr. A. Zainul Fanani, S.Si., M.Kom.** bersama tim pengampu (**Prof. Dr. Nova** dan **Dr. Ruri**) pada Program Doktor Ilmu Komputer (PDIK) Universitas Dian Nuswantoro (UDINUS).

Fokus mata kuliah ini adalah eksplorasi metode kecerdasan komputasi modern (Neural Networks, Fuzzy Systems, Evolutionary Algorithms, Swarm Intelligence, Ensemble & Hybrid Methods) sebagai instrumen melahirkan kebaruan (*novelty*) dan perbaikan performa (*improvement*) pada penelitian Disertasi Doktoral.
